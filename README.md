# George Webb Investigation Navigator

Open `index.html` in any browser.

## Permanent hosting
This is a static site and can be hosted unchanged on GitHub Pages, Cloudflare Pages,
Netlify, Vercel, or any ordinary web server.

## Link mapping
The site uses verified Substack posts where I could verify a stable public post URL.
For subjects where no canonical series-start URL was verifiable, the tile points to
a permanent Substack publication search for that topic instead of inventing a slug.

Edit `links.json` if you later want to substitute a particular canonical starter post.
